## 各工具导入方法

### uBlock Origin（推荐）

1. 打开 uBlock Origin 设置
2. 进入「过滤器列表」→「自定义」
3. 点击「从 URL 导入」
4. 粘贴对应的订阅地址
5. 点击「应用更改」

### AdGuard（桌面端 / 浏览器扩展）

1. 打开 AdGuard 设置
2. 进入「过滤器」→「自定义过滤器」
3. 点击「新建过滤器」
4. 填写名称（如 `FilterFusion`）和订阅地址
5. 点击「保存」

### AdGuard for Android / iOS

1. 打开 AdGuard 应用
2. 进入「过滤器」→「自定义过滤器」
3. 点击「新建过滤器」
4. 填写名称和**手机端**订阅地址
5. 启用该过滤器

### AdGuard Home（DNS 过滤）

1. 打开 AdGuard Home 管理页面
2. 进入「过滤器」→「DNS 过滤」
3. 点击「添加黑名单」
4. 选择「从 URL 添加」
5. 填写名称和 DNS 订阅地址

### Pi-hole（DNS 过滤）

1. 打开 Pi-hole 管理页面
2. 进入「Group Management」→「Adlists」
3. 在「Address」填入 DNS 订阅地址
4. 点击「Add」

## 导入失败三步自查

1. **换一条地址重试** — 三条订阅线路互相独立，首选 `fastly.jsdelivr.net`
2. **浏览器直接打开链接** — 能打开说明是下载器/客户端的网络问题，打不开说明当前网络受限
3. **核对格式** — 确认工具支持 ABP / AdGuard DNS 语法，且地址末尾无多余空格

## 自动更新机制

所有规则文件每天通过 GitHub Actions 自动更新：

- **抓取** — 异步并发从各源下载最新规则
- **合并** — 分类、去重、生成最终文件
- **校验** — 产物完整性校验（规则数、Checksum、头部字段）
- **推送** — 自动提交到仓库，部署 GitHub Pages 并刷新 CDN 缓存

你无需手动更新，广告拦截工具会自动拉取最新版本。此外项目**每两周**发布一次带版本号的离线快照（[Releases](../../releases)），内含 `weekly-rules.zip`，适合离线部署、内网环境或批量导入。

## 规则文件格式

### AdBlock 规则（`adblock-*.txt`）

- 格式：ABP 标准（Adblock Plus 2.0）
- 兼容：uBlock Origin、AdGuard、Adblock Plus、Brave Browser
- 头部：含 Title、Description、Version、Checksum 等元数据
- Checksum：MD5 + Base64（去掉 `=` padding 后 22 字符）；文件内不含空行，以兼容 AdGuard TS / Rust 两种校验实现

### DNS 规则（`dns-blocklist.txt`）

- 格式：AdGuard DNS 过滤格式
- 兼容：AdGuard Home、Pi-hole、DNSCrypt、Clash Premium
- 语法：`||domain^`（拦截域名）、`@@||domain^`（放行域名）
